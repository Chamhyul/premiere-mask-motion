# Mask Motion — Beta

Premiere에서 추적한 **불투명도 마스크의 움직임**을 텍스트·그래픽 등 대상 클립의 **변형(Transform) Position 키프레임**으로 옮기는 UXP 플러그인입니다. After Effects나 중첩 시퀀스가 필요하지 않습니다. 마스크 추적 자체는 Premiere에서 먼저 완료해야 합니다.

## 다운로드와 설치

1. [베타 릴리스](https://github.com/Chamhyul/premiere-mask-motion/releases)에서 **Mask-Motion-0.3.2-beta.1.ccx**를 받습니다. GitHub의 자동 생성 Source code ZIP은 설치 파일이 아닙니다.
2. CCX 파일을 더블클릭하고 Adobe Creative Cloud Desktop의 설치 안내를 따릅니다.
3. Premiere의 **창(Window) → UXP Plugins → Mask Motion**을 엽니다.

사용자에게 **UXP Developer Tool이나 Developer Mode는 필요하지 않습니다.** Premiere 26.0 이상과 Creative Cloud Desktop이 필요합니다. 같은 CCX를 Apple Silicon 맥·인텔 맥·Windows x64에 사용합니다.

## 베타 검증 상태

| 환경 | 상태 |
| --- | --- |
| Apple Silicon 맥 / Premiere 26.5.2 | 개발 도구 로딩 환경에서 핵심 측정·적용 확인 |
| 인텔 맥 | 실제 실행 미검증 |
| Windows x64 | 실제 실행 미검증 |

설치형 CCX의 설치·재실행과 최신 패널의 전체 흐름은 베타 테스트 대상입니다. 자동 테스트 40개 및 문법 검사는 통과했습니다. 베타 버전이므로 **복사한 프로젝트에서 먼저 테스트**해 주세요.

## 사용 방법

1. 원본 비디오 클립의 **불투명도(Opacity)에 마스크**를 만들고 Premiere에서 추적을 완료합니다.
2. 타임라인에서 원본 하나를 선택하고 **클립 전체 측정**을 누릅니다. 재생헤드를 시작점으로 옮기거나 길이를 입력할 필요가 없습니다.
3. 측정 후 원본 마스크를 비활성화합니다. 움직일 텍스트·그래픽 등의 대상 클립을 원하는 시작 위치에 배치하고 선택합니다.
4. **선택한 대상에 적용**을 누릅니다. 새 변형 효과가 추가되고 Position 키프레임이 생성됩니다.

대상은 측정 구간 전체를 포함해야 하며 정방향 100% 속도여야 합니다. 기본 모드는 대상의 기존 효과를 수정하지 않습니다.

## 제한과 주의 사항

- 알파값을 가중치로 한 불투명 영역 전체의 무게중심 이동을 측정합니다. 여러 마스크가 있으면 합쳐진 중심을 따릅니다.
- 화면 전체가 불투명하거나 마스크 대상이 사라지거나 화면 가장자리에 닿으면 측정을 중단합니다.
- 위치 이동만 지원합니다. Scale·Rotation·원근·가림 복원은 지원하지 않습니다.
- 측정 중 다른 비디오 트랙을 잠시 숨기고 완료·중지 시 복구합니다. 강제 종료했다면 트랙 표시 상태를 확인하세요.
- 효과 추가·키프레임 적용·추가 키프레임 정리는 각각 실행 취소 이력에 남을 수 있습니다.
- 자동 좌표 기준을 확인하지 못하면 고급 설정에 대상 원본/그래픽 캔버스의 크기를 입력합니다.
- 언어 및 OS에 따른 효과·알파 렌더 차이는 베타 테스트에서 확인해야 합니다.

자세한 동작·제약·개발 도구 설치는 [개발 및 상세 안내](docs/DEVELOPMENT.md)를 참고하세요.

## 베타 피드백

[Issues](https://github.com/Chamhyul/premiere-mask-motion/issues/new/choose)에 다음 내용을 알려 주세요.

- CCX 설치 / 패널 열기 / 전체 측정 / 대상 적용 / Premiere 재실행 후 패널 열기 각각의 성공 여부
- 문제를 재현하는 순서와 오류 메시지 또는 화면
- 필요한 경우 고급 설정의 **실제 적용 방식으로 진단 → 진단 결과 저장**으로 만든 JSON

진단 JSON에는 클립 이름 등 프로젝트 정보가 포함될 수 있습니다. 공개 첨부 전에 내용을 확인해 주세요. 원본 영상이나 프로젝트 파일은 기본적으로 필요하지 않습니다.

## 개발

외부 npm 패키지나 빌드 과정은 없습니다.

```sh
npm test
npm run check
python3 scripts/package.py
```

마지막 명령은 실행 파일 6개만 포함한 CCX, 설치 안내, SHA-256 체크섬을 `dist/`에 생성합니다. 플러그인 내부 버전은 `0.3.2`, 베타 릴리스 태그는 `v0.3.2-beta.1`입니다.
