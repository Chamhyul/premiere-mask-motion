# Mask Tracker

Premiere의 오브젝트 마스크로 추적한 움직임을 텍스트·이미지·그래픽 클립에 적용합니다.

[설치 안내](INSTALL-ko.md) · [다운로드](https://github.com/Chamhyul/premiere-mask-tracker/releases)

**추적 후 프로젝트를 저장하거나, 마스크를 불투명도에 적용할 필요가 없습니다.**

## 1. 마스크 만들고 추적하기

추적할 대상이 있는 비디오 클립을 선택하고, 오브젝트 마스크를 만든 뒤 필요한 구간을 추적합니다.

## 2. 마스크 선택하고 분석하기

Mask Tracker에서 해당 비디오 클립을 선택합니다. 표시된 목록에서 원하는 마스크를 고르고 **분석**을 누릅니다.

마스크를 수정했거나 다른 클립을 분석하려면 **초기화** 버튼을 누르고 다시 선택합니다.

## 3. 움직일 클립에 적용하기

같은 시퀀스에서 움직일 클립을 선택하고 **적용**을 누릅니다. 크기와 추가 배치는 함께 추가되는 **변형** 효과에서 조절합니다.

추적 구간과 겹치는 시간에만 적용되므로 클립 길이를 맞출 필요는 없습니다. 같은 클립에 여러 마스크를 적용할 수 있으며, 겹치는 구간은 나중에 적용한 결과로 바뀝니다.

분석 중에는 다른 클립이나 시퀀스를 선택해도 됩니다. 대상이 화면 테두리에 걸리면 움직임을 추정하므로 적용 후 확인하세요.

위치 이동만 지원합니다. 추적할 영상은 시퀀스와 같은 해상도여야 하며, 두 클립은 정방향 100% 속도, 추적할 영상의 모션과 마스크 변형은 기본값을 사용합니다.

오류는 [Issues](https://github.com/Chamhyul/premiere-mask-tracker/issues/new/choose)에 알려 주세요.
