# Mask Tracker

Premiere에서 오브젝트 마스크로 추적한 움직임을 텍스트·이미지·그래픽 클립에 적용합니다.

[설치 안내](INSTALL-ko.md) · [다운로드](https://github.com/Chamhyul/premiere-mask-tracker/releases)

## 1. 마스크 만들고 추적하기

1. 타임라인에서 **추적할 대상이 있는 비디오 클립**을 선택합니다.
2. 프로그램 모니터의 **오브젝트 마스크 도구**로 대상을 선택합니다. 필요한 경우 사각형·올가미 선택을 사용합니다.
3. **효과 컨트롤 → 할당되지 않은 마스크**에서 해당 마스크를 선택하고 필요한 구간을 추적합니다.

## 2. 마스크 선택하고 분석하기

1. Mask Tracker를 열고 타임라인에서 해당 비디오 클립을 선택합니다.
2. 자동으로 표시되는 마스크 목록에서 원하는 마스크를 고릅니다.
3. **분석**을 누릅니다.
* 분석이 완료된 후 마스크를 추가하거나 다시 추적했다면, 또는 다른 비디오 클립의 마스크를 분석하고 싶으면 초기화 버튼을 누르세요.

## 3. 움직일 클립에 적용하기

1. 같은 시퀀스에 움직일 클립을 배치하고 원하는 위치에 맞춥니다.
2. 해당 클립을 선택하고 **적용**을 누릅니다.

**각 마스크의 추적 구간과 겹치는 시간에만 적용됩니다. 겹치는 구간은 나중에 적용한 결과로 바뀝니다.** 크기와 추가 배치는 함께 추가되는 **변형** 효과에서 조절하세요.
다른 클립을 분석하려면 **초기화** 버튼을 누르고 클립을 다시 선택합니다.

## 사용 조건
- 추적할 비디오와 움직일 클립은 같은 시퀀스에 배치합니다.
- 추적할 비디오와 시퀀스의 해상도는 같아야 하며, 두 클립 모두 정방향 100% 속도를 사용합니다.
- 추적할 비디오의 모션과 오브젝트 마스크의 위치·크기·회전은 기본값을 사용합니다.
- 위치 이동만 적용하며, 크기·회전 변화는 추적하지 않습니다.
- 대상이 테두리에 걸리면 이동을 추정합니다. 보이지 않거나 추정하기 어려운 구간은 보간 또는 위치 유지로 처리하므로 적용 후 확인하세요.
