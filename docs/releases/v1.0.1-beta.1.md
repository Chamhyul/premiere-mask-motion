# Mask Tracker 1.0.1 Beta 1 — Windows x64

Windows용 설치 EXE를 제공합니다. 네이티브 클립보드 모듈과 UXP 패널을 함께 설치합니다.

## 변경 사항

- Windows에서 요청 파일을 읽은 뒤 스트림을 닫고 처리하도록 수정했습니다. 파일 잠금 때문에 마스크 읽기가 시간 초과되던 문제를 해결합니다.
- MSVC의 Adobe SDK 포인터 선언 및 유니코드 테스트 문자열 컴파일 오류를 수정했습니다.
- 화면 조작 없이 실제 호스트의 마스크 읽기와 클립보드 복원을 검사하는 도구를 추가했습니다.

## 설치

1. Premiere를 종료하고 Creative Cloud Desktop에 로그인합니다.
2. `Mask-Tracker-Windows-x64-1.0.1-beta.1-Setup.exe`를 실행합니다.
3. Premiere의 **환경 설정 → 컨트롤 표면 → 추가 → Mask Tracker**를 선택합니다. 기존에 등록했다면 다시 추가할 필요는 없습니다.
4. **창 → UXP 플러그인 → Mask Tracker**를 엽니다.

기존 설치도 EXE를 실행해 업데이트할 수 있습니다. 설치 파일은 서명되지 않았습니다.

## 확인한 범위

- 실제 Windows Premiere에서 추적된 오브젝트 마스크 `01` 읽기 성공.
- 읽기 전후 기존 클립보드 4개 형식의 크기·해시 일치 및 네이티브 복원·검증 성공.
- JavaScript 테스트, 네이티브 프로토콜 테스트 및 Windows EXE 빌드.

대상 클립 적용과 텍스트·이미지·파일 등 모든 클립보드 입력 조합의 검증은 아직 완료되지 않았습니다. 보존할 수 없는 클립보드 형식은 복사 전에 거부합니다. 이번 릴리스에는 Windows 빌드만 포함합니다.

ZIP은 CCX와 네이티브 모듈을 직접 배치할 때 사용할 수 있습니다. 일반 설치에는 EXE를 사용하세요. `SHA256SUMS.txt`에는 이번 릴리스 파일의 SHA-256 체크섬이 포함됩니다.
